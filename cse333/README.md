# cse333

Pre-quarter head start for CSE 333 (systems programming, C then C++). One folder per exercise, each self-contained:
a header, an implementation, a plain-assert `test.c`, and a Makefile with `-Wall -Wextra -g -fsanitize=address,undefined`.

Planned order: `ht/` chained hash table in C → `ll/` linked list in C + a gdb walkthrough of a deliberate segfault → `fileio/` make + C file I/O.
These are my own from-scratch versions; when the real homework drops, it gets solved fresh from its own spec.
